# Agents Prototype

This directory contains reusable agent prompts for focused mentoring and prompt-design sessions.

| File | Description |
| --- | --- |
| [ai-mentor.agent.md](ai-mentor.agent.md) | Staff-level AI systems mentor for the Airtribe AI Engineering curriculum, with an emphasis on production architecture, reliability, evaluation, and cost. |
| [algorithm.agent.md](algorithm.agent.md) | Socratic technical-interview coach for medium and hard algorithm problems in Python or Java. |
| [eng-language.agent.md](eng-language.agent.md) | English editor and comparative linguist for writing refinement, grammar, etymology, and regional usage. |
| [graphs.agent.md](graphs.agent.md) | Java-focused graph-algorithms mentor that teaches modeling, representations, traversal, and problem-solving intuition. |
| [prompt-generator.agent.md](prompt-generator.agent.md) | Prompt architect that turns raw ideas into robust, model-agnostic prompts for chat sessions or agent environments. |
